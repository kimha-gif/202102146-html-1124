01 벤치마킹 선정과 위계

4대 브랜드 분석

시간대별 전환 3종에 교수님이 알려주신 Birdie를 더해 4개로 정리함.

1
Pura 4
주 비교 기준
시장 선두

시간대별 향 전환을 파는 시장 선두. 400만 대 이상 판매. "홈 향수의 다이슨"

  • 앱 스케줄·타이머로 카트리지 2개 자동 교대
  • 벽면 콘센트 직결식 흰색 플러그인
  • 인플루언서 중심 마케팅, 구독 모델
  • 접근 가능한 프리미엄 포지셔닝
⚠ 카트리지를 계속 사야 함. 6개월 $168
2
Pium
모드 분할 비교
뉴욕 스타트업

집중을 요구하지 않는 주변 경험. 삼성 인큐베이터 출신. Kickstarter 선판매.

  • 캡슐 3개(Morning · Afternoon · Night) 자동 호출
  • 스마트 스피커를 닮은 'Brooklyn' 외형
  • 음성 비서 연동, 스마트 홈 타겟
  • 스타터 키트 $199
⚠ 최근 판매·후기 확인 불가, 시장 지속성 불투명
3

향 전문기업

향료 전문기업 Agan Aroma(50년)의 스마트 디바이스. Indiegogo 20만 달러 모금.

  • 캡슐 4개 세기를 앱으로 개별 조절해 향 믹싱
  • 15분 셔플, 스케줄 기능
  • 네스프레소 머신 형태
  • 본체 $189, 캡슐 팩 $30
⚠ 값이 비싸고 캡슐 구독 필수. 앱 의존성 높음
4
Birdie
반응·형태 — 교수님 제시
덴마크 디자인

기술 제품처럼 보이지 않는 기술 제품. Kickstarter 30일 50만 달러 달성.

  • 800ppm 이하 → 다시 일어섬
  • 벽걸이 노란 새 오브제 외형
  • 앱·디스플레이 없이 몸짓으로 상태 전달
⚠ 공기 상태만 알려줌. 정화 기능 없음
02 핵심 비교

우리 제품과의 차별점

우리 제품은 수면·업무 모드를 바꾸는 향 제품(가칭). 팀 브랜드명이 정해지면 반영함.

비교 항목 Pura · Pium · Moodo Birdie 우리 제품 차별
전환 기준 시각 스케줄 공기 상태 (CO₂) 지금 내 상태 (밝기·자세·자리)
모드 수 시간대 여러 개 상태 2개 (정상, 쓰러짐) 수면·업무 2개로 단순화
작동 방식 앱으로 설정, 자동 실행 센서가 읽고 몸짓으로 보여줌 앱 없이 형태가 바뀌며 향 전환
외형 가전형 (감지기·스피커·커피머신) 노란 새, 의인화 상태를 보여주는 형태 모티프
소모품 카트리지·캡슐 정기 구매 소모품 없음 미정
타겟 스마트 홈 사용자 집·사무실·학교 집에서 일하는 재택근무자
가져올 것
Pura의 감성 마케팅과 구독 모델 + Birdie의 상태를 몸짓으로 보여주는 방식
03 외형·기능 아이디어 후보

4가지 대안

취미는 빼고 수면·업무 중심으로 정리함. 아래 안 중 하나로 좁히기 전 비교용 후보임.

👁
1안: 눈 (Eye)
밝기에 반응함. 밝으면 눈이 뜨며 업무 향, 어두워지면 눈이 감기며 수면 향이 열림. 자동이고 앱이 없음.
필요: 조도 센서, 작은 모터
↕️
2안: 세움·눕힘
자세에 반응함. 세워 두면 업무 향, 눕히면 수면 향이 나옴. Birdie의 쓰러짐과 같은 방식.
특징: 손으로 바꾸고 전원 없이 가능
🔲
3안: 받침 (Dock)
놓인 자리에 반응함. 책상 받침에 두면 업무 향, 협탁 받침에 두면 수면 향이 나옴.
특징: 전원 없이 가능. 자리로 모드 전환
🔮
4안: 향 알갱이
알록달록한 알갱이 하나하나가 향을 담음. 상황(휴식·업무·수면)을 정하면 조합 추천, 나만의 조합으로 바꿀 수 있음.
필요: 알갱이 수집 구조, 상황 설정 입력
참고 향 리서치

수면·업무·휴식 과학적 근거

아로마테라피 메타분석 및 인지과학 연구를 바탕으로 정리함.

😴
수면
라벤더
아로마는 수면의 질을 높임 (한국 메타분석 23편). 단일 향이 혼합 향보다 효과가 크고, 그중 라벤더가 가장 컸음.
→ 수면 모드는 향 1종으로 단순하게
💡
업무
로즈마리
로즈마리 향이 나는 방에서 미래기억 점수 15% 향상, 더 각성함. 라벤더는 반응속도를 떨어뜨림.
→ 업무 향은 로즈마리, 라벤더는 제외
🍊
휴식 (후보)
시트러스
에센셜 오일 메타분석에서 비터오렌지가 불안 줄이기 1위, 레몬도 효과 중간~큼.
→ 현재 후보로만 보류
🧠
공통 원칙
모드마다 고정
학습할 때와 떠올릴 때 같은 향이 있으면 단어 회상이 좋아짐 (맥락 의존 기억).
→ 모드마다 향을 고정, 자주 바꾸지 않음
수면 연구는 노인·폐경 여성·중환자 대상이 많아 일반 사용자에게 그대로 말하긴 어려움. 취미 향은 기준이 없어서 제외.
